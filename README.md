# 🐕 היומן של מייפל (Maple Journal)
### מערכת מודרנית למעקב אימוני פרידה, האכלות ומשימות אילוף
**פתרון Google Apps Script Web App עצמאי — ללא שרתים חיצוניים, ללא פרויקט ענן (Zero GCP), ו-100% חינמי.**

---

## 📖 אודות הפרויקט

הפרויקט **היומן של מייפל** פותח במקור כאפליקציית Python המבוססת על Streamlit ומתחברת לגיליון נתונים ב-Google Sheets.
כדי לפתור את חסרונות המערכת הישנה (תלות בשרת חיצוני, הגדרות מורכבות של Google Cloud Platform ו-Service Accounts, חסימות עומס קבועות עקב מגבלת מכסה של 60 קריאות לדקה — HTTP 429, וחוויית מובייל מסורבלת), המערכת עברה **מיגרציה מלאה ל-Google Apps Script Web App**.

האפליקציה החדשה מוטמעת ישירות בתוך גיליון ה-Google Sheets כ-Container-Bound Web App, נטענת בפחות משנייה במובייל, ומספקת ממשק עברי מודרני, חלק ומרהיב.

## ⚡ השוואת ארכיטקטורות: מה השתנה?

| מאפיין | מערכת קודמת (Streamlit + GCP) | מערכת חדשה (GAS Web App) |
| :--- | :--- | :--- |
| **שרתים ותשתיות** | דורש שרת חיצוני (Streamlit Community Cloud / VPS) | **0 שרתים** — רץ על גבי התשתית העולמית של Google |
| **הגדרות ענן ואימות** | דורש פרויקט GCP, Service Account וקובץ מפתחות JSON סודי | **0 הגדרות ענן** — פועל ישירות תחת חשבון ה-Google שלכם |
| **מגבלות קריאה (Quota)** | נחסם תכופות ב-HTTP 429 (מגבלת 60 קריאות לדקה ב-Sheets API) | **ללא שגיאות 429** — גישה ישירה בתוך הזיכרון של Sheets |
| **עלויות** | עלול לגרור עלויות שרת בעתיד | **חינמי לחלוטין ולתמיד** |
| **מהירות טעינה** | 5–8 שניות (הקמת קונטיינר Python וטעינת ספריות כבדות) | **פחות משנייה (Sub-second)** הודות ל-Data Bootstrapping |

| **שיתוף עם המשפחה** | דורש הוספת הרשאות לגיליון עבור כל משתמש בנפרד | **קישור אחד קבוע** שפועל לכל בני הבית מהנייד ללא צורך בהרשאות |

## 🌟 יכולות ומודולים מרכזיים

### 1. 🏃 הישארות לבד (Separation Training)
* **טופס אימון חכם**:
  * בחירת תאריך ושעת יציאה (עם מנגנון LTR ייעודי המונע היפוך שעות).
  * חישוב אוטומטי של ברירת מחדל למשך האימון מתוך השיא ההיסטורי:  
    $$\text{default\_duration} = \text{round}\left(\frac{\max(\text{Duration})}{2.0} \times 4\right) / 4$$
  * באנר חישוב דינמי בזמן אמת: מציג את שעת היציאה, שעת החזרה המשוערת וסה״כ שעות.
  * דירוג לחץ מ-1 עד 5 עם הסברים בעברית ואימוג'ים ייעודיים (🟢 רגועה לחלוטין עד 🚨 פאניקה).
* **גרף עומס מתקדם (Separation Intensity Curve)**:
  * שקלול עומס לכל אימון לפי רמת הלחץ: $\text{Duration} \times (\text{StressLevel} / 3.0)$.
  * מודל עצימות מתגלגל של 7 ימים עם **דעיכה מעריכית (7-day Half-Life Decay)**:  
    $$\text{Intensity}(t) = \sum_{k=0}^{\min(6, t)} 0.5^k \times \text{Daily\_Weighted}(t - k)$$
  * רצועות אחוזונים דינמיות: אזור כחול (עומס קל — אחוזון 33), אזור ירוק (טווח עבודה אידיאלי — אחוזון 90), ואזור אדום (עומס יתר/שיא).
  * נקודות פיזור צבעוניות (Scatter) של אימונים בודדים לפי רמת הלחץ.
  * מלבני הצללה אנכיים בצבעים מותאמים עבור שהיות ממושכות מחוץ לבית (`Away_Log`).
  * מסנני טווח זמן (7 ימים, 30 יום, חודשיים, הכל).
* **תיעוד היעדרות ממושכת**:
  * שמירת תאריכי התחלה וסיום עם ולידציה אוטומטית.
  * 6 מיקומים קבועים בצבעים ייחודיים (משק יאיר, ניקול, חברים בת"א, שמירה בבית, פנסיון, אחר).

### 2. 🦴 האכלות (Feeding Tracker)
* תיעוד ארוחות (בוקר / ערב / אחר) עם שעה וכמות בכוסות.
* מחשבון גרמים אוטומטי מובנה (1 כוס = 400 גרם).
* מתג "האם סיימה הכל?" (כן 🟢 / לא 🔴).
* גרף עמודות יומי מקובץ ומוערם (Stacked Bar Chart) המציג את סך האוכל היומי מחולק לפי האם סיימה את המנה.

### 3. 🎓 משימות ותרגילים (Tasks & Training Logs)
* קטלוג תרגילי אילוף (שם, תדירות ודגשים לביצוע).
* תיעוד ביצוע תרגיל עם דירוג הצלחה מ-1 עד 5.
* גרף פיזור (Scatter Plot) המציג את התקדמות הציונים לאורך זמן לכל תרגיל בנפרד.

### 4. 📊 היסטוריה ויומן מלא (CRUD)
* צפייה בכל הרשומות לפי קטגוריות.
* עריכה כירורגית של כל שורה ישירות מחלון Modal נקי.
* מחיקת שורות מאובטחת.
* **תיקון באג ה-`smart_update` של Streamlit**: תמיכה מלאה וחלקה בעדכונים מרובים במקביל ללא איבוד נתונים.

## 📱 התקנה ופריסה מהירה (2 דקות)

למדריך המלא הכולל תמונות והסברים מפורטים, עיינו בקובץ:  
👉 **[מדריך הפריסה המלא — DEPLOYMENT.md](./DEPLOYMENT.md)**

### תמצית השלבים:
1. פתחו את הגיליון: [Google Spreadsheet — Maple Journal](https://docs.google.com/spreadsheets/d/1URUI3gpIa2wx_gQdEawCDRp8Tw4h20gun2zeegC-Oz8).
2. עברו אל **הרחבות (Extensions)** -> **Apps Script**.
3. הדביקו את תוכנו של [`gas/Code.gs`](./gas/Code.gs) לתוך `Code.gs`.
4. צרו קובץ HTML חדש בשם `Index` והדביקו את תוכנו של [`gas/Index.html`](./gas/Index.html).
5. לחצו על **פריסה (Deploy)** -> **פריסה חדשה (New deployment)** -> סוג: **יישום אינטרנט (Web app)**:
   * **Execute as**: Me (`your_email@gmail.com`)
   * **Who has access**: Anyone
6. אשרו את ההרשאות הראשוניות וקבלו את כתובת האפליקציה למובייל!

## 💻 הרצה ובדיקה מקומית (Local Testing)

קובץ ה-Frontend (`gas/Index.html`) תוכנן במיוחד כך שיכיל מנוע סימולציה ומערך נתוני Mock עצמאי.
ניתן להריץ אותו ישירות בכל מחשב ללא צורך בחיבור ל-Google:

1. פתחו את הקובץ `gas/Index.html` ישירות בכל דפדפן (Chrome / Safari / Edge).
2. או הריצו שרת מקומי קל משקל:
   ```bash
   cd gas
   npx serve .
   # או: python3 -m http.server 8080
   ```
3. פתחו את הכתובת `http://localhost:8080/Index.html` בדפדפן. המערכת תזהה שהיא פועלת בסביבה מקומית ותאפשר בדיקה מלאה של כל הטפסים, הגרפים והעריכות עם נתוני הדגמה.
